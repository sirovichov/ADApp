# МЧС: Тревога БПЛА (Android)

Мобильное приложение для Android, которое берёт данные с **официального сайта МЧС России**
(mchs.gov.ru) и предупреждает об **угрозе/атаке БПЛА**:

- 📡 Периодический фоновый опрос ленты сводок МЧС (WorkManager, каждые 15 минут).
- 🔎 Фильтрация сообщений по ключевым словам: *БПЛА, БПЛА-тревога, дрон, беспилотник, сбит* и т.д.
- 🔔 Срочные push-уведомления (high priority, heads-up, вибрация) о новых предупреждениях.
- 📋 Главный экран — список актуальных алертов с регионом, временем и ссылкой на источник.
- ♻️ Ручное обновление кнопкой или свайпом вниз.
- 💾 Офлайн-кэш последних полученных данных (работает без сети).
- 🌐 Тап по уведомлению/алерту открывает оригинальную сводку на сайте МЧС.

## Структура проекта

```
app/src/main/java/ru/mchs/uavalert/
├── data/
│   ├── UavAlert.kt        # модель предупреждения
│   ├── MchsRepository.kt  # HTTP + парсинг JSON-API сайта МЧС, фильтр по БПЛА
│   └── AlertCache.kt      # локальный кэш (SharedPreferences)
├── service/
│   └── AlertWorker.kt     # WorkManager: фоновый опрос + уведомления
└── ui/
    ├── MainActivity.kt    # список алертов, pull-to-refresh, разрешения
    └── AlertAdapter.kt    # RecyclerView-адаптер
```

## Требования

- Android Studio (Hedgehog+), JDK 17, Android SDK 34
- minSdk 24 (Android 7.0), targetSdk 34

## Сборка

```bash
./gradlew assembleDebug          # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew installDebug           # установка на подключённое устройство
```

Либо просто откройте папку проекта в Android Studio и нажмите **Run**.

## Важные замечания

1. **Источник данных.** Приложение обращается к публичному JSON-API портала
   `https://www.mchs.gov.ru/api/news/list?...` (константа `API_URL` в `MchsRepository.kt`).
   МЧС периодически меняет структуру сайта/API — если парсер перестал находить данные,
   поправьте URL или имена полей в `parseAlerts()`; код устойчив к изменениям и не падает,
   а возвращает пустой список.
2. **Уведомления.** На Android 13+ при первом запуске запрашивается разрешение
   `POST_NOTIFICATIONS`. Отказать — и приложение не будет предупреждать в фоне.
3. **Это не официальное приложение МЧС.** Оно лишь агрегирует публичные сообщения
   ведомства. При реальной угрозе руководствуйтесь официальными каналами оповещения
   (сирены,push «ГТОК», сайт mchs.gov.ru).
